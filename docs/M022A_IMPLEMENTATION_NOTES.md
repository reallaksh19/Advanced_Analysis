# M022-A implementation notes

- The contract layer is source-format specific and remains upstream of canonical geometry.
- `stagedjson-resolved-analysis/v1` is a concrete sealed artifact, not a diagram-only concept.
- Process values are effective per-entity StagedJSON enrichment outputs; entity-order inheritance is prohibited.
- Material/section assignments may still use explicit governed inheritance, such as M008-C generated-pipe adjacency, through later resolver outputs.
- No operating material state may be accepted without a governed evaluation temperature and a material table that brackets it.
- No one-way restraint may be converted to a bilateral fixed DOF without an explicit linearization authority.
