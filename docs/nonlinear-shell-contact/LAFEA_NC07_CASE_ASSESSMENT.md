# LAFEA-NC NC-07 — Case Assessment Receipt Contract

NC-07 governs case-specific code-assessment receipts above the reusable NC-06 package. It does not automatically accept an asset, declare fitness for service, calculate remaining-strength authority, or authorize production execution.

## Pinned scope

Each assessment case is immutably bound to an asset, defect, approved assessment basis, qualified NC-05 dimensionless cell, source input set, measurement record, model receipt, calculation ledger, report, independent review, owner disposition, and retention record.

The evaluator requires qualified NC-06 package and NC-05 mechanics receipts. Every case must remain within the exact approved assessment basis and qualified mechanics cell. Nearest-cell substitution, inferred inputs, output fitting, unresolved applicability, and beneficial uncertainty treatment are prohibited.

## Required evidence

Ten evidence domains cover upstream receipt binding, case identity, input custody, applicability, qualified-cell binding, calculation-ledger reproduction, uncertainty, independent review, owner disposition, and report retention. Equation, unit-conversion, and ledger-reproduction tolerances are pinned by contract.

A complete package may qualify `codeAssessmentQualified` for the registered case receipt. The result is a traceable assessment record, not an automatic pass or fitness-for-service decision.

## Exclusions

Automatic acceptance, fitness for service, remaining strength, failure pressure, damage, fracture, fatigue, production execution, and merge authority remain excluded from NC-07 contract qualification.
