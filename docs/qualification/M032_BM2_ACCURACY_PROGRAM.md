# M032 — BM2 Accuracy Program

## Purpose

M032 converts BM2 work into a sequence of measured mechanics hypotheses. It does not add another solver architecture, input layer, or reporting abstraction.

The program is stacked on the M031 qualified-mechanics authority at commit:

```text
140433982e60dbc6add0b4b8b1785a494fbe69b5
```

That head has complete custody for 5,598 strict CASE 3/4/6 scalars and reproduces:

```text
passing = 4,404
failing = 1,194
untraced = 0
coverage = COMPLETE
```

## Non-negotiable controls

- The 5,598-scalar denominator and row identities are frozen.
- Comparison tolerances and zero/near-zero rules are not changed to manufacture improvement.
- Each mechanics PR declares one primary hypothesis.
- No candidate may reduce passing scalars below 4,404 or increase failing scalars above 1,194.
- Unresolved classifications, unmatched solver rows, and untraced scalars remain zero.
- Every mechanics change runs BM1, BM2, BM3, and the full linear-core suite.
- Output-state fitting and fitted restraint engagement are prohibited.
- A green workflow is not a parity claim; parity requires all 5,598 scalars to pass.

## M032-A — Baseline and clustering

M032-A adds no mechanics changes. It runs the exact M031 comparison and generates deterministic ledgers:

```text
reports/bm2-accuracy-program-clusters.json
reports/bm2-accuracy-program-clusters.csv
```

Clusters are generated by:

- case;
- result family;
- case/result family;
- source component;
- station or report pair;
- field or DOF;
- comparison mode;
- retained cause code;
- mechanics hypothesis.

The report includes failure counts, pass rates, zero/near-zero failure counts, relative-error distributions, signed bias, maximum absolute differences, and the highest-severity rows for each cluster.

## Downstream hypothesis order

The generated cluster report, not code volume or intuition, controls priority. Initial candidate hypotheses are:

1. element-end action recovery and local-axis custody;
2. junction stiffness and branch ownership;
3. remaining bend directional flexibility;
4. unilateral restraint reaction/complementarity deltas;
5. rigid load and stiffness distribution;
6. exact-zero and near-zero channel behavior;
7. independent perturbation cases for stiffness identification.

Each downstream PR must state the selected hypothesis, predicted affected clusters, prohibited unrelated paths, and measured before/after 5,598-scalar result.

## Promotion

A mechanics candidate may advance only when:

```text
denominator = 5,598
coverage = COMPLETE
unresolved classifications = 0
unmatched solver rows = 0
untraced scalars = 0
passing >= 4,404
failing <= 1,194
BM1/BM3/linear-core = PASS
```

M032-A itself is baseline-only and must reproduce exactly 4,404 passing and 1,194 failing scalars.
