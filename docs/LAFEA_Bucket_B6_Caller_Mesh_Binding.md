# LAFEA Bucket B6 — Governed Caller-Mesh Binding

## 1. Purpose

B6 binds the five T4 continuum application templates to an existing, reconstructed NB-T4A caller-mesh evidence record. It does not generate a mesh and does not authorize continuum execution.

```text
schema: lafea-template-caller-mesh-binding/v1
stage:  LAFEA.3
family: T6
```

Templates:

```text
C2D-BRACKET-GUSSET
C2D-CLAMP-EAR
C2D-LUG-PINHOLE
C2D-NOZZLE-REPAD-SECTION
C2D-PIPE-PAD-SECTION
```

## 2. Parent graph

```text
B1 release record
  ├─ template semantic hash
  ├─ compiler binding
  ├─ compilation hash
  ├─ handoff hash
  └─ required mesh-authority contract

B2 CURRENT compatibility receipt
  ├─ LAFEA.3 registry entry
  ├─ current composition root
  ├─ current lifecycle profile
  └─ current mesh requirement

source-authority record hash
  └─ sourceHash
       └─ canonicalModelHash
            └─ analysisGeometryHash
                 └─ meshProfileHash + meshHash
                      ├─ stage-authorized mesh authority
                      └─ quality evidence

additional application mappings
  ├─ material-region evidence
  ├─ load-edge evidence
  └─ boundary-edge evidence
```

Every engineering parent is explicit. Display buffers, render packets, `meshConfig`, viewport tessellation and array position are not accepted as mesh authority.

## 3. Existing NB-T4A evidence

The workspace adapter reconstructs the supplied:

```text
lafea-analysis-mesh-evidence/v1
```

through `createLafeaAnalysisMeshEvidence`. The reconstructed record must be byte-equivalent to the supplied record and must retain:

```text
stageId       = LAFEA.3
status        = CURRENT
qualification = PASS
element type  = T6
releaseState  = RELEASE_NOT_QUALIFIED
```

T3 fallback and Q8 substitution are rejected for the five current T4 compiler bindings even though the broader LAFEA.3 stage can support those element families under other governed routes.

## 4. Mapping evidence

B6 does not infer material regions or load/boundary edges from node order. Three exact records are required:

```text
materialRegionEvidence
loadEdgeEvidence
boundaryEdgeEvidence
```

Each contains:

```text
applicability = REQUIRED
evidenceHash
qualification = PASS | PENDING | BLOCK
```

Rules:

```text
PASS    requires canonical SHA-256 evidenceHash
PENDING requires evidenceHash = null
BLOCK   retains the blocking evidence hash when available
```

## 5. Dispositions

```text
BOUND
  NB-T4A mesh parents are current and all three mapping records pass.

MAPPING_EVIDENCE_PENDING
  the mesh is current, but source-authority-record identity or one or more
  application mapping records remain pending.

BLOCKED
  one or more mapping records block the template binding.

STALE
  reserved for a subsequently revalidated binding whose parent identities no
  longer match. Tampered or stale input is rejected before a new record is made.
```

Even `BOUND` means template evidence binding only. It does not mean production mesh qualification or execution readiness.

## 6. Immutable non-claims

Every B6 record states:

```text
compilerGeneratedMesh      = false
productionMeshQualified    = false
engineExecutionAuthorized  = false
recoveryProduced           = false
convergenceProduced        = false
codeAssessmentProduced     = false
releaseQualified           = false
```

These fields are generated by the contract and cannot be supplied or overridden by the caller.

## 7. Anti-drift checks

The B6 qualification covers:

```text
all five T6 continuum template identities
CURRENT/PASS NB-T4A mesh reconstruction
T6-only template binding
pending and passing mapping records
blocked mapping retention
missing source-authority-record identity
T3 rejection
tampered mesh evidence
stale B2 receipt rejection
template/release/receipt mismatch
unauthorized template and stage
invalid mapping applicability
PASS without evidence hash
PENDING with evidence hash
unknown keys
binding hash tampering
mutable binding rejection
source guards against execution, meshing and lifecycle registration
```

## 8. Authority retained

```text
continuum template mesh evidence: bindable
production mesher: absent
continuum engine execution: unauthorized
recovery: absent
convergence: absent
code assessment: absent
release qualification: absent
general T7D: unauthorized
```

B6 does not modify LAFEA.3 numerical code, compiler output, stage registry, composition root, lifecycle profile, mesh thresholds, shell formulation, benchmark expected values or release state.
