# LAFEA Non-Bucket NB-T4B — Recovery-to-Render Producer

## Disposition

NB-T4B is a bounded result-evidence package for `LAFEA.3`, `LAFEA.4` and `LAFEA.5`. It consumes an explicit NB-T4A-qualified analysis mesh and an already accepted retained stage calculation. It creates exact `EXECUTION` and `RECOVERY` lifecycle evidence and a sealed `LafeaRenderPacket.v2`.

It does not create an analysis mesh, invoke a solver, recover a new engineering stress quantity, smooth across elements, perform convergence, create an SCL or structural-stress result, assess code, issue a report or qualify release.

## Exact chain

```text
CURRENT SOURCE AUTHORITY
  -> CURRENT/PASS CANONICAL_MODEL
  -> CURRENT/PASS ANALYSIS_GEOMETRY
  -> CURRENT/PASS NB-T4A ANALYSIS_MESH
  -> CALCULATION_ACCEPTED_BY_STAGE_CONTRACT
  -> CURRENT/PASS EXECUTION
  -> CURRENT/PASS RECOVERY
  -> RESULT_READY
  -> display-only LafeaRenderPacket.v2
```

`CODE_READY` and `RELEASE_QUALIFIED` remain false. `CONVERGENCE` and `REPORT_EVIDENCE` are not produced by this package.

## Retained authority

### LAFEA.3

- `T3`: retained element-constant stress may be selected for a block contour.
- `T6` and `Q8`: a caller must select an exact retained integration-point stress.
- No nodal stress becomes authoritative.
- The producer does not invoke Gauss-to-node projection.
- Display vertices are duplicated per element, so a shared node is never used to average across material, thickness, feature or load discontinuities.

### LAFEA.4

The production route remains `CST_DKT_TRI3_THIN_SHELL_V1`. A caller must select an exact retained integration point and fixed surface (`BOTTOM`, `MIDSURFACE` or `TOP`). The selected surface tensor component is repeated across the element only as display geometry. No nodal shell stress, extrapolation, averaging, drilling degree of freedom, MITC4 or MITC3 authority is introduced.

### LAFEA.5

The package reads the retained `rawShellResult` generated by the caller-authored host-shell footprint route. It does not add trunnion, pad or weld stiffness, pressure superposition, contact, SCL or code authority.

## Display tessellation

The governed display policy is:

```text
ELEMENT_LOCAL_CORNER_TESSELLATION_NO_CROSS_ELEMENT_VERTEX_SHARING/V1
```

- T3, T6 and CST+DKT shell elements use their three corner nodes for one display triangle.
- Q8 uses its four corner nodes for two display triangles.
- Midside nodes are not promoted to independently recovered display values in this package.
- Every display triangle retains an exact source element index and pick-map entry.
- The display tessellation is not `ANALYSIS_MESH` evidence.

## Field and lineage rules

The initial controlled quantity set is `SIGMA_X`, `SIGMA_Y` and `TAU_XY`. Units must exactly match the retained stage stress unit. Every display-field row retains:

- element identity;
- selected scalar value;
- exact retained result source path;
- retained authority layer.

The V2 packet binds:

- source hash;
- analysis-geometry artifact hash;
- NB-T4A analysis-mesh artifact hash;
- execution artifact hash;
- recovery artifact hash;
- deterministic display-geometry hash;
- deterministic render-profile hash;
- producer reference.

All packet vertex values are marked `PRODUCER_PROJECTED_DISPLAY_ONLY`.

## Fail-closed conditions

The producer rejects, at minimum:

- LAFEA.1, LAFEA.2 and LAFEA.6;
- unaccepted calculation results;
- source-authority mismatch;
- stale canonical-model, analysis-geometry or analysis-mesh parents;
- tampered or blocking NB-T4A mesh evidence;
- stale display-geometry or render-profile identity;
- unit mismatch;
- missing load case, element, integration point or shell surface;
- T3 integration-point requests;
- T6/Q8 evidence without retained integration-point authority;
- shell element/nodal requests;
- unsupported stress quantities;
- package or packet-lineage tampering.

## Non-claims

NB-T4B does not claim:

- production geometry-to-mesh generation;
- smoothed or projected nodal engineering stress;
- SCL, membrane-plus-bending classification or structural stress;
- three-level convergence;
- code compliance;
- MITC production dispatch;
- LAFEA.6 support;
- release qualification.
