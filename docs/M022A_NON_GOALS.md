# M022-A non-goals

- alter the InputXML ingestion, canonicalization, ground-truth, source-binding, or solver path;
- generalize the M008-C catalog implementation;
- supply extended hot material data;
- resolve support assemblies into solver constraints;
- build canonical geometry;
- invoke B-2.5 or downstream solve/recovery;
- add UI.
